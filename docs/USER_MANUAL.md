# User Manual

1. Open the frontend and upload a text-based PDF or DOCX resume under 10 MB.
2. Choose a seeded target role.
3. Run the analysis.
4. Review the score, matched skills, prioritized gaps, recommendations, and roadmap.
5. Use History to reopen a previous analysis; details are reloaded from the backend.

The score is an application-specific compatibility indicator, not a hiring guarantee. The system reports only skills detected in the resume and does not invent experience, achievements, or certifications.
